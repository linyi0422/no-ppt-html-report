Sylan-no-ppt / Board HTML

一次 Codex 任务复盘

这个示例展示的是：完成一次 AI 协作任务后，如何直接生成可展示的复盘页。左侧用于讲清楚结论，右侧用于展示任务路径。

核心判断

no-ppt 的首发场景应优先打穿任务复盘，而不是泛化成所有演示工具。

01 背景

用户和 AI 完成了工具调研、Excalidraw 本地验证、repo 定位讨论，需要把结果沉淀成可公开展示的 GitHub Pages 示例。

02 已完成

  • 验证 Excalidraw 可以本地调用。
  • 明确 no-ppt 的核心不是 PPT 克隆，而是 AI 生成的 HTML 展示产物。
  • 把 HTML report 和白板型 HTML 作为当前两个主要方向。

03 决策

仓库先沿用当前结构，通过 GitHub Pages 展示示例；命名后续可以再调整，但产品口径先收敛到 Sylan-no-ppt。

04 下一步

  • 增加更多任务复盘模板。
  • 增强导出能力，例如 PNG/PDF。
  • 沉淀 Codex / Claude Code 生成 recipe。
