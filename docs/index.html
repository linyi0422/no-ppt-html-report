可调式汇报展示库

这个仓库沉淀的是一种 可调式汇报展示方式：把复盘、方案、问题说明做成带控件的 HTML 页面，现场调整版式、信息重心和截图状态。

这种展示方式可以怎么描述

  • 可调式汇报页
  • 参数化汇报稿
  • 交互式问题说明页
  • playground-style report demo

案例 01｜谈薪复盘展示 一个可调式汇报页案例。支持上半区、问题区、问题卡分别调节，适合 GitHub Pages 直接展示。

怎么跟 AI 说

关键不是让 AI “做一个 HTML”，而是说明：这是一页可展示的汇报稿，需要带可调控件，方便现场调重点和截图。

我想把下面这段材料做成一个“可调式 HTML 汇报页”，不要做 PPT。

使用场景：
我要把它发给【目标对象】，希望对方快速理解【核心问题/核心结论】。

内容材料：
【粘贴原文、复盘、方案、会议记录或问题说明】

要求：
1. 页面本身就是可展示的汇报稿，不要做成普通文章。
2. 信息结构分成 3-5 个模块，最重要的问题/结论要做成视觉中心。
3. 加入调节面板，可以调字号、行距、模块间距、重点区域大小、关键问题字号。
4. 加一个“纯净模式”，隐藏控制面板，方便截图或公开展示。
5. 所有 CSS 和 JS 写在一个 HTML 文件里，方便直接打开和部署到 GitHub Pages。
