AI-first HTML presentation artifacts

Sylan-no-ppt

面向 Codex / Claude Code 协作用户的展示方式实验库。完成任务或讨论后，直接生成可以展示、微调、交互、截图和发布的 HTML，而不是再打开 PPT。

当前首发场景：任务复盘

AI 在任务完成后已经拥有上下文，最适合直接整理背景、过程、决策、结果、风险和下一步，并生成展示页面。

推荐协作流程

01和 AI 完成任务或讨论。
02让 AI 整理背景、过程、结果和下一步。
03生成 Report HTML 或 Board HTML。
04在浏览器里微调，切到纯净模式后展示或截图。
